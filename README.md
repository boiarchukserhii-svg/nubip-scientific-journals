# Наукові журнали НУБіП України

Публічний PWA-каталог у світло-фіолетовій палітрі для аспірантів та науковців.

## Що є в першій версії

- 16 журналів — **лише** видання, посилання на які надані замовником;
- головний дашборд із підрахунком категорій саме в цьому вибраному переліку;
- каталог із пошуком за назвою, напрямом і кодом спеціальності;
- картка журналу з прямим посиланням на сайт редакції;
- підбір журналу за спеціальністю, без рекомендації виключених видань;
- пам'ятка авторові, адаптивна верстка, PWA-маніфест та офлайн-кешування.

## Як змінювати каталог

Відкрийте `journals.js` — там окремо від дизайну зберігаються всі журнали, коди спеціальностей і посилання.

- `catalogGroup`: розділ категорії на сторінці університету — це **не** підтвердження актуального статусу МОН;
- `verifiedCategory`: категорія, окремо перевірена за джерелом редакції, з `statusSource`;
- `excluded: true`: журнал зазначений як виключений з Переліку МОН;
- `legacyCodes: true`: застарілі коди, не прирівняні автоматично до нових;
- `url`: офіційний сайт журналу, наданий замовником.

Для оновлення кешу після публікації змініть значення `CACHE_NAME` у файлі `service-worker.js`.

## Публікація на GitHub Pages

1. Створіть новий **публічний** репозиторій, наприклад `nubip-scientific-journals`.
2. Завантажте **вміст** цієї папки в корінь репозиторію, усі файли розміщуються **в корені репозиторію**, вкладених папок немає.
3. У Settings → Pages оберіть Deploy from a branch, гілку `main`, каталог `/ (root)`.
4. Після публікації відкрийте адресу `https://<login>.github.io/nubip-scientific-journals/`.
5. На Android у Chrome скористайтеся меню «Додати на головний екран» / «Встановити».

Вимоги: HTTPS для PWA; локальний перегляд можливий через простий HTTP-сервер, а не безпосередньо з `file://`.

## Обмеження даних

Дані підготовлено за сторінкою НУБіП і наданими посиланнями 17.11.2026. Для частини видань статус фаховості потребує додаткової перевірки. Це попередній каталог для пошуку, **не** автоматичне підтвердження відповідності публікації вимогам до захисту дисертації. У розділі А за каталогом один журнал, хоча його редакція повідомляє про категорію Б за наказом № 928 від 11.06.2026. «Сучасне птахівництво» позначено як виключене з Переліку МОН.


## Полегшене завантаження без папок

1. Розпакуйте ZIP у папку на комп'ютері.
2. Перейдіть у репозиторій GitHub → Add file → Upload files.
3. Відкрийте розпаковану папку, натисніть Ctrl+A і перетягніть **усі 10 файлів** на сторінку GitHub (не сам ZIP).
4. Натисніть Commit changes.
5. Settings → Pages → Deploy from a branch → main → / (root) → Save.

**Важливо:** файл `index.html` має бути прямо в корені репозиторію, а не в додатковій папці.


## Оновлення 1.2 — чистий інтерфейс

- Прибрано зазначені службові пояснення та зайві підписи в розділах «Огляд» і «Підбір видання»
- Крапка наприкінці видимих текстових блоків прибирається автоматично; крапки між реченнями залишаються
- Текстовий шрифт: **Zakon Text** (локально встановлений шрифт), системний шрифт як резервний
- Офіційне джерело Zakon Text: https://mincult.gov.ua/zakon/
- Файли шрифту навмисно не поширюються в архіві; для однакового показу на всіх пристроях потрібне окреме дозволене вебпідключення шрифту
- Колишні цифрові коди 201 і 203 перетворено на H1, 204 — на H2, 211 — на H6 відповідно до таблиці відповідності наказу МОН №1625 (19.11.2024). Відображена відповідність кодів не замінює підтвердження чинних спеціальностей конкретного журналу
- Футер: чотири кнопки (відділ науково-технічної інформації, сайт НУБіП, каталог журналів, авторство з функцією копіювання)
- У розділі автора – офіційна сторінка МОН «Наукові фахові видання»


## Оновлення 1.3 – тематичні піктограми і підготовка вебшрифту Zakon

- Кожне з 16 видань отримало власну контурну тематичну SVG-піктограму замість піктограми-«решітки». Властивість `icon` задається окремо для кожного журналу у `journals.js`
- Піктограми вбудовані у код, працюють без додаткових файлів, мережі та зовнішніх бібліотек
- CSS-файл `styles.css` містить чотири `@font-face` для вебпідключення **Zakon Text** (звичайний, жирний, курсив і жирний курсив) з `font-display: swap` і резервним шрифтом
- **Файлів Zakon Text у ZIP немає.** Потрібно окремо отримати Zakon Text на офіційному сайті Міністерства культури України: https://mincult.gov.ua/zakon/
- Для ввімкнення вебшрифту на всіх пристроях завантажте в корінь GitHub-репозиторію офіційні файли гарнітури під назвами `ZakonText-Regular.otf`, `ZakonText-Bold.otf`, `ZakonText-Italic.otf`, `ZakonText-BoldItalic.otf`, **або** з тими ж основами назв у форматах `.woff2` чи `.ttf`. Важливо: перейменуйте саме відповідні накреслення, не довільні файли
- Після завантаження вебшрифт автоматично підключиться з GitHub Pages за допомогою правила `@font-face`; окремо редагувати CSS не потрібно. За відсутності файлів працює локально встановлена гарнітура або резервна Georgia
- Якщо офіційний архів містить інші назви чи структуру, зіставте чотири стилі за їхньою реальною назвою (Regular, Bold, Italic, Bold Italic) або змініть адреси в `@font-face`. Не використовуйте Zakon Decor чи Zakon Letterpress – у них інші умови ліцензування
- Шрифт не додається до обов'язкових файлів PWA-кешу, щоб відсутність шрифту не блокувала встановлення застосунку

**Перевірка:** у браузері Chrome відкрийте DevTools → Network → Font або Computed → Rendered Fonts. Якщо Zakon Text не завантажено, спершу перевірте наявність файлів шрифту й правильність назв у корені репозиторію
